## 性能

参考机器：Mac16,10，16 GiB，macOS 27.0.1 / 26A434。Release，5,000 历史+200 收藏，含中英文、长文本、图片和 1 MiB 片段，每项 30 次。

| 版本 | 热呼出 p95 | 查询至绘制 p95 |
| --- | --- | --- |
| 0.4.0 基线 | 776.58 ms | 510.07 ms |
| 0.4.1 最终候选 | 86.85 ms | 131.61 ms |

方法为程序调用真实面板和查询更新，等待后台结果并执行 AppKit 布局/显示；不包含物理键盘事件送达。候选满足此测法的 ≤200 / ≤150 ms 目标。基线从 v0.4.0 独立源码快照运行相同测试与数据，未修改正式 0.4.0。上述数值来自最终源码的完整 Release 检查。

优化：减少重复结果刷新和详情重建、缓存来源选项与缺失应用图标，长文本先绘制 4,000 字符、Show More 继续加载，复制保留完整内容。

本地记录位于 `outputs/0.4.1-release/panel-benchmark*.json`，不随源码分发。

## 实机限制

计算机交互服务返回过隔离 Release 面板的完整 AX 状态，可见 5,000 条历史、来源、多选和 Stack 入口；其后点击、AX、bundle ID 重连及截图均超时。另建唯一名称/ID 并注册的 QA bundle 也未恢复。

因此真实中文输入法、跨 TextEdit/浏览器/代码编辑器粘贴、完整 VoiceOver、小屏和文字放大、实际键盘端到端时间仍未宣称通过。macOS 12 设备不可用；Intel 已按用户要求退出本版范围。

共享文件夹同步已通过两份独立数据库和实际事件文件回归，未使用两台实体 Mac 或真实 iCloud 网络执行端到端测试。共享文件明文且保留历史版本，外部已有副本不随本机退出清空删除。
