# PasteLite 0.4.1 完成计划

日期：2026-11-07（Asia/Shanghai）。基线：v0.4.0 / `08e90eb`。

目标：0.4.1 / build 41，macOS 12+，**仅 Apple Silicon / arm64**。按用户本轮指令，自 0.4.1 起停止 Intel 开发、构建和发布；0.4.0 旧安装包保留。

状态：下表的功能已实现，Debug 167 / Release 166 个测试、ARM 安装包及更新回滚验证通过，尚未公开发布。实际结果与设备限制见 [候选验收](acceptance-0.4.1.md)。

| 需求 | 交付边界 |
| --- | --- |
| 选中视觉 | 低饱和淡底、细边框、左侧标记；语义文字颜色；筛选和模式切换降低色块面积；主按钮深强调色配白字；明暗主题与八种强调色对比度检查 |
| 提示细节 | 长分组名完整提示；片段 1 MiB 限制说明、UTF-8 字节数；保存失败保留草稿并恢复输入焦点 |
| 导入、导出、备份 | 版本化 JSON，分组、名称、片段、完整格式和图片；文件仍是引用；预检、原子合并、重复安全、失败回滚；不覆盖本地已有编辑 |
| OCR | Vision 本地后台识别；查看、复制、搜索、重跑、取消；按数据域/ID/hash 持久化；机密内容不识别 |
| 来源筛选 | 与分组、类型、查询组合；两种模式各自记住条件；失效条件退回全部 |
| 多选与合并 | 选择顺序编号；换行/空行/空格/无分隔符；不能提取文字或机密项拒绝整次合并 |
| Paste Stack | 队列顺序、重排、移除、清空、取消；成功才出队；失败保留队首；明确重设目标才能切换应用 |
| 模板变量 | 片段内 `{{name}}`、中文变量、重复变量；调用时填写并预览；复制或安全粘贴结果，不改变源片段；至多 64 个变量、展开后至多 1 MiB |
| 本地脚本 | 用户选择 `.sh`，明确点击 Run，UTF-8 stdin → stdout，结果预览后复制；错误/取消/五秒及大小限制；使用用户正常权限，不自动运行 |
| MCP | 默认关闭；本机 loopback HTTP、每次启动随机 Bearer token；只读历史/收藏文字检索，排除机密；不提供修改、删除或粘贴 |
| 文件夹同步 | 用户选择共享文件夹，如 iCloud Drive；只同步收藏/分组，不同步历史；不可变 JSON 事件、事务 outbox、失败重试；时间戳+UUID 决胜，删除标记防复活；明文范围在开启前说明 |
| 性能 | 分页增加长正文预览，完整复制保留；缓存来源筛选选项及缺失应用图标；减少重复刷新和预览重建；相同数据对比 0.4.0 |
| ARM 发布 | ARM runner、arm64 目标、单架构 DMG/ZIP/校验和，更新器只选 arm64 资产；拒绝 Intel 打包参数 |

同步冲突规则：同一条目采用较新逻辑时间戳，同时间以 UUID 排序；两台设备独立保存同一原样内容时收敛为较小的条目 UUID。共享 JSON 保留历史版本，不加密；用户可通过文件夹服务管理共享权限及历史。清空收藏传播删除；退出清空会停止同步、清理本机及未发送载荷，外部已有副本保留。

实机中文输入法、VoiceOver、跨应用粘贴和 macOS 12 只在真实执行后标为通过。Intel 不再属于 0.4.1 验收范围。
