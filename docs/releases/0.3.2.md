# PasteLite 0.3.2

Privacy, keyboard, and history reliability improvements.

## Changes

- Reusing concealed content no longer restarts its 24-hour lifetime. The fixed expiry deadline is saved across app restarts.
- Clipboard changes observed during application switches are skipped when their source cannot be attributed safely, including switching to an excluded app and back before the next poll.
- Tab and Shift-Tab use native focus navigation. Command-C respects selected text, and Return respects focused AppKit buttons.
- Undo remains visible alongside an error. A failed restore keeps its payload available for retry within the five-second undo window, and successful retry clears the error.
- Copy failures from recent menu items reopen the history panel, and a persistent pause banner makes recording status clear.
- New captures and ordering changes preserve the selected result. Deleting a selected result chooses its neighbor, and search/filter changes return to the first result.
- Selected history rows and filter counts use readable foreground colors across all eight accents.
- Source-app icons use a main-actor cache, and website-preview metadata is copied before being handed to the main actor.

## Compatibility and upgrade

Requires macOS 12 or later. Separate Apple Silicon and Intel downloads are available.
Version **0.3.2 (build 32)**.

Existing history and settings are preserved. On first launch, the history database
migrates concealed items to a separate expiry deadline using their stored copy
time. The original capture time of items reused in older versions cannot be recovered.

Source attribution deliberately favors privacy: a copy made close to an application
switch may be skipped, even when the source app is allowed.

This release is **ad-hoc signed and not notarized**. macOS may require
**System Settings → Privacy & Security → Open Anyway** on first launch.

## Verification

- Debug: 112 tests in eight suites pass with complete strict concurrency checking and warnings treated as errors.
- Release: 111 tests in seven suites pass with the same checks. The Debug-only preview-export suite is excluded.
- Clean Apple Silicon and Intel Release builds; both DMGs mount and pass bundle identity, version/build, minimum OS, signature, archive-content, and SHA-256 checks.
- Apps copied from both DMGs launch with isolated, paused recording and empty history storage. The Intel app was exercised through Rosetta on Apple Silicon.
- The packaged Apple Silicon app passes actual update staging and installation success/rollback checks.
- Repeated quit waits for history and attachment clearing in an isolated Debug app.
- Release bundles contain no development fixtures, personal build paths, or history databases.

Native Intel hardware, macOS 12 runtime behavior, complete VoiceOver navigation,
and a manual cross-app paste walkthrough require separate acceptance.
