# PasteLite 0.4.0 — local release candidate

A saved library for reusable clipboard content, commands, and text snippets.

This candidate has not been published.

## New features

- Save original clipboard content independently of rolling history.
- Organize saved content with names and custom groups.
- Create and edit reusable plain-text and code snippets.
- Search saved names, content, paths, and source apps; combine group and type filters.
- Switch History/Saved with Control-Tab, create snippets with Command-N, edit them with Command-E, and save with Command-Return.
- Undo deletion of history or saved content within five seconds.

## Upgrade behavior

Ordinary legacy pins become Ungrouped saved items. Their original clipboard
formats and usage information are preserved. Concealed legacy pins remain
protected history and retain their fixed expiry.

Save to Library keeps original clipboard formats. Save as Text Snippet creates
an editable plain-text copy and keeps the original history entry.

Clearing history keeps saved content. Clear All Data on Quit includes history,
saved items, snippets, groups, and their attachments. Saved files remain
references to the original files.

## Candidate verification

- Debug: 142 tests in ten suites.
- Release: 141 tests in nine suites.
- Complete strict concurrency checks and warnings treated as errors.
- Apple Silicon and Intel builds, signed bundle/plist checks, and verified DMGs.
- Actual packaged update staging plus bundle replacement and rollback tests.

Manual cross-app pasting, complete VoiceOver and input-method walkthroughs,
end-to-end panel latency, macOS 12 runtime behavior, and physical Intel hardware
require additional acceptance. See `docs/acceptance-0.4.0.md`.

Requires macOS 12 or later. Separate Apple Silicon and Intel artifacts.
