# PasteLite 0.3.0

A new native macOS interface for finding, previewing, and reusing clipboard history.

## New in this release

- New Stack app icon, redesigned menu bar, and a clear two-column history panel.
- Light/dark themes, eight accent colors, and a compact mode.
- Type filters, source app icons, search highlighting, content previews, pinned items, and usage counts.
- Five-second delete undo and safer clear-history confirmation that keeps pinned items.
- Keyboard-first actions, plain-text paste switching, layered Escape, and paste/copy feedback.
- Recording pause, five recent menu bar items, and General, Storage, Privacy, and Updates settings.
- Masked concealed clipboard items with 24-hour expiry, app exclusions, and clear-on-quit.
- Website metadata previews are off by default and can be enabled in Privacy settings.
- Stable/Beta update checks, architecture-aware downloads, verification, and installation rollback.

## Review fixes

- Preserve concealed pasteboard markers when copying or pasting sensitive items.
- Cancel delayed reveals when selection changes and hide revealed content at expiry.
- Prevent pending delete/undo operations from restoring cleared records or replacing a newer copy.
- Clear all history and attachments before quitting, including repeated quit requests.
- Preserve rich text and support native color/file/URL representations when pasting plain text.
- Roll back pin changes if storage pruning fails.

## Upgrade notes

Existing clipboard history migrates in place. Return now performs the selected primary action.
Choose **Settings → General → When you choose an item → Copy to clipboard** for copy-only behavior.
Without Accessibility permission, the primary action copies to the clipboard.

Requires macOS 12 or later. Separate Apple Silicon and Intel downloads are available.
Version 0.3.0, build 30.

## Verification and limitations

- 90 automated tests, including existing paste/focus safety checks and the new review regressions.
- 22 native renders covering both appearances, all settings pages, preview types, compact mode, and search.
- Apple Silicon and Intel Release builds, signed bundle checks, mounted DMG checks, and SHA-256 checksums.
- Actual update staging plus successful replacement, failed-launch rollback, and existing-backup protection exercised on isolated fixtures.
- Repeated quit exercised in an isolated app, with zero history items and attachments remaining.

A fresh manual cross-app UI walkthrough could not be completed because the desktop interaction
service was unavailable. macOS 12 runtime testing requires a separate machine.

This release is **ad-hoc signed and not notarized**. macOS may require **System Settings → Privacy & Security → Open Anyway** on first launch.
