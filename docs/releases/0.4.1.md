# PasteLite 0.4.1

A softer interface and a complete toolkit for reusable clipboard content.

- Use a softer selected row with a fine outline, side marker and readable text in light and dark mode.
- Back up saved groups, names, snippets, original clipboard formats and image payloads; import atomically without overwriting local edits.
- Recognize and search image text locally with Apple Vision; filter content by source app.
- Select and merge text in a chosen order, or queue items in Paste Stack for safe one-at-a-time pasting.
- Fill `{{variables}}` before reusing a snippet. Choose and explicitly run a local shell text transform, preview its output, then copy it.
- Optionally enable authenticated, read-only MCP searches on this Mac.
- Sync saved content and groups through a chosen shared folder, with edit/delete propagation, conflict ordering and retryable event delivery.
- Show full group names, snippet size limits and reliable draft retry focus; use a single Settings scene.
- Improve long-text rendering and panel responsiveness.

Version 0.4.1, build 41. macOS 12+, **Apple Silicon only**. Intel support ends
with 0.4.0. Ad-hoc signed, not notarized.

The database keeps schema v4 with compatible OCR/sync extension tables.
Backups support up to 256 MiB per file. File entries remain references.
Folder sync writes readable JSON change history: users choose and control the
shared folder. Clearing all data on quit disables sync and clears this Mac;
existing shared copies remain. Local scripts run with the user's normal access,
only after selecting a script and clicking Run. MCP is off by default.

Full validation and outstanding device/interaction coverage are documented in
`docs/acceptance-0.4.1.md`. Release checks: Debug 167 tests, Release 166 tests, complete strict concurrency
and warnings-as-errors; mounted ARM app launch, actual packaged update staging,
replacement and rollback, repeated-quit cleanup, and old-version database read
compatibility passed. Thirty-sample native rendering p95: show 86.85 ms,
query-to-display 131.61 ms on the recorded reference Mac. Physical key delivery,
full manual interaction, VoiceOver and macOS 12 runtime remain unverified.
