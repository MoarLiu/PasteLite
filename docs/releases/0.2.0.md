# PasteLite 0.2.0

PasteLite **0.2.0 (build 20)** — 2026-09-09.

## Improvements

- Delete edits the search field while it has focus. Input-method composition is handled before history shortcuts.
- Direct paste checks the target app, focus, Accessibility permission, and clipboard contents before sending the command. Closing history or starting a new action cancels the pending operation.
- The Paste button names the actual destination app.
- Clipboard history reports storage failures and warns when only temporary, in-memory storage is available.
- Images load on demand, with downsampled previews and bounded caching. Database work runs off the UI thread.
- Native clipboard colors and text containing NUL characters survive capture and copying.
- Repeated status messages are no longer cleared by cancelled timers.

## Compatibility and installation

- macOS 12.0 or later; separate Apple Silicon (`arm64`) and Intel (`x86_64`) downloads.
- Both builds are ad-hoc signed and are **not notarized**. Gatekeeper may block the first launch; use System Settings → Privacy & Security → Open Anyway to open the app.
- The existing history database format is retained.

## Validation

- 49 automated tests passed in both Debug and Release configurations.
- Coverage includes search editing, input-method composition, native color round trips, multiple file items, delayed attachment loading, storage failure feedback, cancellation, and simulated paste interruptions.
- Real cross-application paste acceptance and testing on macOS 12 / physical Intel hardware remain manual validation items.
- Both Release DMGs were mounted and their bundle contents and signatures verified against the staged apps.
- Startup smoke checks passed natively on Apple Silicon and under Rosetta for the Intel build, each with an isolated history database.
- Distributed binaries declare macOS 12.0 as their minimum system version and contain no local user build paths.
