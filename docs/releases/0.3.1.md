# PasteLite 0.3.1

Small improvements to reusing clipboard history and updating PasteLite.

## Changes

- Copying an item from history refreshes its time and moves it to the front of its section. Pinned items remain in the pinned section.
- The updated time and order are saved across app restarts, without creating a duplicate entry.
- Copy and paste actions complete silently. Error messages remain available when an action fails.
- Checking for updates downloads and verifies a new version inside PasteLite. Choose **Install & Relaunch** when ready; updating does not require opening GitHub.
- Background updates follow your automatic-update preferences, and prepared updates remain ready until installation. The optional release-notes link is clearly labeled as opening GitHub.

## Compatibility

Requires macOS 12 or later. Separate Apple Silicon and Intel downloads are available.
Existing history and settings are preserved. Version 0.3.1, build 31.

This release is **ad-hoc signed and not notarized**. macOS may require **System Settings → Privacy & Security → Open Anyway** on first launch.

## Verification

- 101 automated tests pass in eight suites, including manual/background update behavior, download and install retries, prepared-update preservation, history reuse, ordering, persistence, and existing paste delivery checks.
- Clean Apple Silicon and Intel Release builds; both DMGs mount and pass bundle, signature, architecture, minimum OS, archive-content, and SHA-256 checks.
- Apps copied from both DMGs launch with isolated settings and storage. The Intel app was exercised through Rosetta on Apple Silicon.
- The packaged Apple Silicon app passes actual update staging and installation success/rollback checks.
- Repeated quit waits for history and attachment clearing in an isolated debug app.

Native Intel hardware, macOS 12 runtime behavior, and a manual cross-app paste walkthrough were not rechecked for this patch.
A manual update UI walkthrough could not be completed because the desktop interaction service timed out; the update flow is covered by controlled tests.
